# AffiqResume

A premium, two-page freelance developer profile for Affiq Rahman.

## Contents

- `index.html` — developer profile and selected work
- `styles.css` — responsive and A4 print styles
- `affiq-rahman-logo.webp` — dark-theme branding
- `logolighttheme.webp` — print branding
- PDF — ready-to-share developer profile

## Usage

Open `index.html` in a browser.

Use **PRINT / SAVE PDF** to export the two-page A4 document. Review the print preview before sharing.
